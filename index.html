메일 작성

EmailJS 발송 설정 미설정 — 메일 앱으로 대체 발송

배포 시에는 저장소의 config/emailjs.config.js에 설정을 입력하면 모든 사용자가 실제 메일을 발송할 수 있습니다.

  1. emailjs.com에서 무료로 가입합니다(월 200건 무료).
  2. Email Services 탭에서 Add New Service를 눌러 Naver 또는 Gmail을 SMTP로 연결합니다.
  3. Email Templates 탭에서 템플릿을 만들고 To {{to_email}} · CC {{cc_email}} · Subject {{subject}} · Body {{message}} · Reply-to {{reply_to}} 변수를 사용합니다. 서식 포함 본문은 {{{message_html}}}을 사용합니다.
  4. Account → API Keys에서 Public Key를 복사합니다.
  5. 설정 파일을 채우기 전에는 아래에 Public Key · Service ID · Template ID를 입력하고 이 브라우저에 저장을 눌러 주세요.
